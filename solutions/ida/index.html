IDA · Intelligent Document Analyzer

문서 데이터를
정량 근거로 분석 Document data,
analyzed with quantitative evidence

IDA는 MetaInsight의 제품 경험을 기반으로, 구조화된 문서·레코드 데이터에서 키워드 클러스터와 시계열 시그널을 찾고 분석 결과를 인사이트로 정리하는 문서 분석 AI 솔루션입니다. Built on the MetaInsight product experience, IDA is a document analytics AI that finds keyword clusters and time-series signals in structured document and record data, and packages the results as insights.

Product Scope

문서·레코드 분석을 위한 핵심 기능Core features for document and record analysis

IDA는 텍스트와 날짜 축이 정리된 문서·레코드 데이터를 기준으로 분석을 시작합니다. 업로드, 컬럼 매핑, 클러스터링, 정량 평가, 인사이트 생성까지 이어지는 흐름을 하나의 화면 경험으로 제공합니다.IDA starts from document and record data that has a text axis and a date axis. Upload, column mapping, clustering, quantitative evaluation, and insight generation are all delivered as a single, unified screen experience.

문서·레코드 업로드Upload documents and records

CSV, Excel, Parquet 파일을 업로드하고 텍스트, 날짜, 금액, 그룹, 식별자 컬럼을 화면에서 확인하며 분석 조건을 구성합니다.Upload CSV, Excel, or Parquet files, review the detected text/date/amount/group/identifier columns on screen, and configure the analysis.

키워드 클러스터링Keyword clustering

비슷한 키워드와 문서 항목을 자동으로 묶고, 각 클러스터가 시간에 따라 어떻게 변화하는지 정량적으로 비교합니다.Group related keywords and document items automatically, then compare how each cluster shifts over time — quantitatively.

정량 근거 기반 인사이트Evidence-backed insights

C1 장기 트렌드, C2 모멘텀 유지, C3 최근 가속 기준을 바탕으로 등급과 점수를 산출하고 자연어 인사이트를 제공합니다.Compute grades and scores from three criteria — C1 long-term trend, C2 momentum, C3 recent acceleration — and deliver natural-language insights.

Analysis Workflow

업로드부터 인사이트까지 이어지는 운용 흐름A flow that runs from upload to insight

사용자는 복잡한 코드 없이 분석 파일을 올리고, 자동 감지된 컬럼을 검토한 뒤 프리셋을 선택해 분석을 실행합니다. 결과는 요약 지표, 차트, 항목 상세, 자연어 인사이트로 나누어 확인합니다.Users upload a file with no code, review the auto-detected columns, pick a preset, and run the analysis. Results show up as summary metrics, charts, item detail, and natural-language insights.

Upload

분석할 문서·레코드 데이터를 업로드하고 지원 형식을 확인합니다.Upload the documents or records to analyze and verify the supported file format.

Map Columns

텍스트와 날짜 컬럼을 중심으로 분석에 필요한 필드를 매핑합니다.Map the fields the analysis needs, anchored on the text and date columns.

Evaluate

키워드 군집을 만들고 트렌드 강도, 모멘텀, 최근 가속을 평가합니다.Build keyword clusters and score them on trend strength, momentum, and recent acceleration.

Review Insights

요약 지표, 상세 항목, AI 또는 템플릿 기반 인사이트를 검토합니다.Review summary metrics, item detail, and AI- or template-based insights.

Signal Criteria

정량 평가 엔진의 세 가지 기준Three criteria behind the quantitative scoring engine

단순 키워드 빈도보다 중요한 것은 지속성, 현재성, 변화 속도입니다. IDA는 각 클러스터를 독립 기준으로 평가해 설명 가능한 점수와 등급으로 정리합니다.Persistence, recency, and rate of change matter more than raw keyword frequency. IDA evaluates each cluster against these independent criteria and turns them into explainable scores and grades.

C1 — 장기 트렌드C1 — Long-term trend

시간이 지나며 꾸준히 증가하는 클러스터인지 확인합니다.Does this cluster grow steadily over time?

C2 — 모멘텀 유지C2 — Momentum

최근 구간의 활동이 기준선보다 높은 상태를 유지하는지 봅니다.Is recent activity holding above the baseline?

C3 — 최근 가속C3 — Recent acceleration

현재 시점에 가까워질수록 격차가 더 커지는지 평가합니다.Is the gap widening as we approach the present?

Operation & Expansion

분석 엔진을 제품으로 운용하기 위한 기반The product foundation that runs the analysis engine

MetaInsight는 분석 엔진만이 아니라 계정, 프로젝트, 결과 저장, 내보내기, 모바일 대응 화면까지 포함한 제품형 구조를 갖추고 있습니다. IDA는 이 기반 위에서 기업 문서·규제·과제 데이터 분석 영역으로 확장됩니다. MetaInsight is more than an analytics engine — it includes accounts, projects, saved results, export, and mobile-ready screens. IDA extends that foundation into enterprise document, regulatory, and program data analysis.

SaaS 운용 구조SaaS operating structure

JWT 인증, 프로젝트 단위 관리, 사용량 제한 등 SaaS 제품 운용에 필요한 기본 구조를 갖춥니다.JWT auth, per-project management, usage limits — the basics required to run as a SaaS product are in place.

도메인 확장Domain expansion

R&D 과제, 특허, 리테일, 금융 리스크처럼 텍스트와 날짜 축이 있는 데이터로 분석 대상을 확장할 수 있습니다.Push the analysis target into any data with text and date axes: R&D programs, patents, retail, financial risk.

반복 탐색Iterative exploration

국가, 분야, 기간, 프리셋 등 조건을 조정하며 같은 데이터에서 다른 관점의 시그널을 확인합니다.Vary country, field, time window, and preset to surface different signals from the same data.
